# Machine-Generated Text Detection 

This repository contains the code and experiments for a Natural Language Processing (NLP) pipeline designed to classify Italian texts as either **Human-written** or **Machine-generated**. 

The project is inspired by the **EVALITA** (Evaluation of NLP and Speech Tools for Italian) campaign, specifically targeting the challenge of detecting artificial text generated by modern Large Language Models (LLMs) in the Italian language.

## Dataset Context
The data used in this project consists of an enriched Italian dataset tailored for the machine-generated text detection task. It is split into **Training, Validation, and Test sets** (e.g., `train_final.pkl`, `val_final.pkl`, `test_final.pkl`). The dataset includes texts authored by humans and texts synthetically generated by AI, labeled accordingly for binary classification.

## Project Structure

The pipeline is divided into four main tasks, representing a progressive exploration from traditional Machine Learning baselines to state-of-the-art Deep Learning models:

### Task 1: Linear SVM & N-grams
* Explores traditional bag-of-words and lexical approaches.
* Extracts word and character n-grams to train a Linear Support Vector Machine (SVM).
* Implements rigorous linguistic configuration definitions and hyperparameter tuning (Model Selection) via GridSearch to establish a solid baseline.

### Task 2: Linear SVM & Non-Lexical Features
* Shifts the focus from semantic content to the structural and stylistic aspects of the text.
* Extracts engineered non-lexical features (e.g., punctuation frequencies, average sentence length, uppercase ratios, and POS tags).
* Analyzes feature importance and model uncertainty to understand how stylistic artifacts differentiate humans from machines.

### Task 3: Linear SVM & Word Embeddings
* Implements dense vector representations for documents using pre-trained Italian Word Embeddings.
* Tests different aggregation strategies (Mean, Sum, Max) and Part-of-Speech (POS) filtering (All, Semantic, Structural).
* Evaluates generalization and overfitting through detailed Hinge Loss and Macro-F1 gap analysis across different data splits.

### Task 4: Neural Language Model Fine-Tuning (BERT)
* Leverages state-of-the-art Transformer architectures to capture deep contextual representations.
* Fine-tunes a pre-trained Italian BERT model (`dbmdz/bert-base-italian-cased`) for binary Sequence Classification over 3 epochs.
* Evaluates final performance on the Test set using Probability/Logit extraction, PR, and ROC curves to comprehensively compare its discriminative power against the previous SVM baselines.
* Note: The fine-tuning phase was executed in a cloud environment (Google Colab with a T4 GPU) due to computational constraints, while the evaluation is handled locally.
